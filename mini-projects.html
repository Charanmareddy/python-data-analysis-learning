PROJECT WORKSHOP

Learn by solving a real question.

Each project below includes a complete example you can run, a small dataset, explanations of the steps, and a guide to reading the result. The sample data is fictional and included directly in the code.

01 / RETAIL · PANDAS + NUMPY + CHARTS

What are our best-selling product categories?

We will combine order details with a product lookup, calculate monthly revenue, flag months around the typical total, and chart the category trends.

Pandascombine and summarize the tablesNumPylabel totals using a thresholdMatplotlibadd chart titles and labelsSeaborndraw the category trend lines
Step 1: Understand the small dataset

Each order row has a date, product, quantity, and unit price. A second table maps each product to a category. Revenue means quantity multiplied by unit price.

Step 2: Run the complete example
import pandas as pd
import numpy as np
import matplotlib.pyplot as plt
import seaborn as sns

# A few example order lines, not real customer data.
orders = pd.DataFrame({
    "date": ["2025-01-05", "2025-01-18", "2025-02-03",
             "2025-02-16", "2025-03-02", "2025-03-20"],
    "product": ["Coffee", "Tea", "Coffee", "Bread", "Tea", "Bread"],
    "units": [10, 6, 12, 8, 10, 12],
    "unit_price": [3.00, 4.00, 3.00, 2.00, 4.00, 2.00],
})
products = pd.DataFrame({
    "product": ["Coffee", "Tea", "Bread"],
    "category": ["Beverages", "Beverages", "Bakery"],
})

# Add category labels to each order using the product name.
orders = pd.merge(orders, products, on="product", how="left")
orders["date"] = pd.to_datetime(orders["date"])
orders["revenue"] = orders["units"] * orders["unit_price"]
orders["month"] = orders["date"].dt.strftime("%b")

# Add the months in calendar order so the chart reads left to right.
month_order = ["Jan", "Feb", "Mar"]
orders["month"] = pd.Categorical(
    orders["month"], categories=month_order, ordered=True
)
monthly = (orders.groupby(["month", "category"], observed=True,
                          as_index=False)["revenue"].sum())
monthly_totals = monthly.groupby("month", observed=True)["revenue"].sum()

# NumPy compares each month's total with the median monthly total.
threshold = np.median(monthly_totals.to_numpy())
monthly_summary = monthly_totals.rename("revenue").reset_index()
monthly_summary["sales_level"] = np.where(
    monthly_summary["revenue"] >= threshold, "At or above typical", "Below typical"
)
print(monthly_summary.to_string(index=False))

# Seaborn draws the data; Matplotlib adds the labels and title.
ax = sns.lineplot(data=monthly, x="month", y="revenue",
                  hue="category", marker="o")
ax.set(title="Monthly revenue by product category",
       xlabel="Month", ylabel="Revenue (USD)")
plt.tight_layout()
plt.show()

In a Python file, type >= as shown in the code itself; the angle brackets are displayed safely here.

Step 3: Read the result

The monthly totals are January $54, February $52, and March $64. Their median is $54, so January and March are labeled “At or above typical,” while February is “Below typical.” The chart shows beverage and bakery revenue separately.

Why the steps matter: the merge attaches readable categories; the grouping adds revenue within each month and category; NumPy applies a simple threshold. The example is tiny, so the trend is only a practice example—not a business conclusion.

  2. Change one unit price, then explain which month and category changed.
  3. Replace the median threshold with a target you choose and explain why.
  4. What could go wrong if the product lookup contained two rows for the same product?
02 / STUDENT OUTCOMES · PANDAS + NUMPY + CHARTS

How do study hours relate to assessment scores?

We will handle a missing score, calculate a typical score and percentile, flag scores for review, and make a scatterplot. This explores association; it cannot prove that study hours caused a score.

Pandasinspect and clean student rowsNumPycalculate a percentile and make labelsMatplotliblabel the chart for readersSeabornshow study hours against scores
Step 1: Understand the small dataset

Each row is a fictional student record. One score is missing to demonstrate a clear cleaning decision. The analysis excludes that row only from score-based calculations.

Step 2: Run the complete example
import pandas as pd
import numpy as np
import matplotlib.pyplot as plt
import seaborn as sns

students = pd.DataFrame({
    "student": ["A", "B", "C", "D", "E", "F"],
    "study_hours": [2, 4, 6, 3, 5, 1],
    "score": [65, 80, 92, 70, 88, np.nan],
})

# Keep the original table and make a score-complete analysis table.
scored = students.dropna(subset=["score"]).copy()
scored["score"] = scored["score"].astype(int)

average_score = np.mean(scored["score"].to_numpy())
score_75th = np.percentile(scored["score"].to_numpy(), 75)
scored["review"] = np.where(scored["score"] >= 75,
                            "Meets practice target", "Review")

print(f"Students with scores: {len(scored)}")
print(f"Average score: {average_score:.1f}")
print(f"75th percentile: {score_75th:.1f}")
print(scored[["student", "score", "review"]].to_string(index=False))

ax = sns.scatterplot(data=scored, x="study_hours", y="score")
ax.set(title="Study hours and assessment score",
       xlabel="Reported study hours", ylabel="Assessment score (out of 100)")
plt.tight_layout()
plt.show()

The target of 75 is an example practice threshold. It is not a recommended grading rule.

Step 3: Read the result

Five students have recorded scores. Their average is 79.0, and the 75th percentile is 88.0. The labels mark scores of 75 or higher for practice review. The scatterplot places each scored student by study hours and score.

Interpret carefully: this tiny dataset cannot tell us that studying more caused a higher score. Other factors may matter, and self-reported hours may be inaccurate.

03 / HOSPITAL SERVICE · PANDAS + NUMPY + CHARTS

Where are patient waits longest?

We will summarize fictional waiting times by department, calculate a high percentile, and chart the distribution so both typical and unusually long waits are visible.

Pandasorganize and group wait recordsNumPycalculate the 90th percentileMatplotlibformat and label the figureSeaborncompare department distributions
Step 1: Understand the small dataset

Each row represents one fictional visit. Waiting time is measured in minutes. Do not use identifiable patient information in learning projects.

Step 2: Run the complete example
import pandas as pd
import numpy as np
import matplotlib.pyplot as plt
import seaborn as sns

visits = pd.DataFrame({
    "department": ["Emergency", "Emergency", "Emergency", "Emergency",
                   "Clinic", "Clinic", "Clinic", "Clinic"],
    "wait_minutes": [18, 35, 42, 12, 10, 25, 30, 15],
})

# Summarize the middle wait and a high-wait threshold by department.
summary = visits.groupby("department")["wait_minutes"].agg(
    median_wait="median",
    p90_wait=lambda values: np.percentile(values.to_numpy(), 90),
).reset_index()
print(summary.to_string(index=False, formatters={
    "median_wait": "{:.1f}".format,
    "p90_wait": "{:.1f}".format,
}))

# Show every observation's distribution rather than only one average.
ax = sns.boxplot(data=visits, x="department", y="wait_minutes")
ax.set(title="Patient waiting time by department",
       xlabel="Department", ylabel="Wait (minutes)")
plt.tight_layout()
plt.show()
Step 3: Read the result

The emergency department has a median wait of 26.5 minutes; the clinic median is 20.0 minutes. The clinic 90th percentile is 28.5 minutes and the emergency 90th percentile is 39.9 minutes. The boxplot compares the spreads, while the 90th percentile focuses on a high-wait threshold. Each department has only four example visits, so the results are illustrative and not reliable service estimates.

Why show more than a median? Two departments can have similar typical waits but different long-wait experiences. The boxplot and percentile help raise questions for further investigation.
