TABLES / PANDAS

Pandas questions

Beginner: What is a DataFrame?

A two-dimensional labeled table with rows and columns. Each column can have its own data type, making it useful for mixed tabular records.

Beginner: How do you inspect a new dataset?

Preview a few rows, check its shape, inspect column types and non-missing counts, then summarize missing values and categories.

Intermediate: When would you use loc?

Use loc for label-based selection, including filtering rows with a condition and choosing named columns.

Intermediate: What can make a merge produce too many rows?

A key may occur more than once on one or both sides. Check key uniqueness and row counts before and after merging.

Scenario: A sales file has blank prices and duplicated order IDs. What do you do?

First determine whether duplicates are valid line items or accidental copies. Quantify missing prices, check other fields, consult the data definition, and record the cleaning decision before calculating revenue.

NUMBERS / NUMPY

NumPy questions

Beginner: What is an ndarray?

NumPy's multidimensional array, designed to store values in a consistent structure and support efficient numerical operations.

Beginner: What do shape and dtype describe?

Shape gives the length along each dimension. Dtype describes the kind of values stored, such as integers or floating-point numbers.

Intermediate: What does axis mean?

It identifies the direction of an operation. For a two-dimensional grid, axis 0 reduces down rows and axis 1 reduces across columns.

Intermediate: What is broadcasting?

NumPy applies compatible values or arrays across dimensions automatically. Shapes must be compatible, so always check them when results look unexpected.

Scenario: A monthly target array will not combine with daily results. What do you check?

Inspect both shapes and the mapping between each day and month. Reshape or index only after confirming the intended alignment; a mathematically valid broadcast can still be logically wrong.

CHARTS / MATPLOTLIB

Matplotlib questions

Beginner: What is the difference between a Figure and an Axes?

The Figure is the full canvas. An Axes is an individual plotting area placed on that canvas.

Beginner: Which chart would you choose for a time trend?

A line chart is often a clear choice for ordered time values. Label the time period and metric, and keep dates in order.

Intermediate: Why keep the Figure and Axes returned by subplots?

They make it clear which chart is being changed, especially with multiple charts, and give direct access to labeling and formatting methods.

Intermediate: What should you check before sharing a figure?

Readability, labels and units, legend clarity, scale, layout, and the saved file itself at its intended display size.

Scenario: A chart exaggerates a small difference. What do you inspect?

Inspect axis limits and baseline, then choose a scale that communicates the comparison fairly. State any deliberate truncation clearly.

STATISTICAL VISUALS / SEABORN

Seaborn questions

Beginner: How does Seaborn relate to Matplotlib?

Seaborn builds on Matplotlib and provides higher-level statistical plotting functions, especially for tidy, table-shaped data.

Beginner: What is hue used for?

Hue maps a category to color so groups can be compared within one chart. Too many categories can make the chart hard to read.

Intermediate: What does a barplot display?

It displays an estimate, often a mean by default, and may show an uncertainty interval. It is not a count of every observation.

Intermediate: When is a boxplot useful?

When comparing distributions across categories. It summarizes quartiles and flags values outside whiskers as potential outliers—not automatically as errors.

Scenario: Two groups have very different sample sizes. What do you communicate?

Show the sample sizes or underlying observations where appropriate, explain the estimate and uncertainty, and avoid making strong conclusions from a visual alone.

QUICK ANSWERS

Frequently asked questions

Do I need to memorize every method?

No. Learn the main ideas, practice common workflows, and become comfortable finding official documentation. Explain why you chose a method.

Which library should I learn first?

Start with Pandas for familiar tables, then build numerical intuition with NumPy and visualization skills with Matplotlib and Seaborn.

Can I use Seaborn and Matplotlib together?

Yes. Seaborn returns Matplotlib axes for many plots, so you can use Seaborn to create a statistical chart and Matplotlib to refine labels or layout.
