PRACTICE STUDIO

Small steps. Real progress.

Use these prompts after reading a library guide. Write your answer, run your code on a tiny dataset, and explain what the result means.

PANDAS

Table thinking

  1. Load a small employee CSV and inspect its first rows.
  2. Find which columns have missing values.
  3. Filter staff in one department and select two fields.
  4. Calculate headcount by department.
  5. Join employee records to a department lookup and check the row count.
NUMPY

Number thinking

  1. Create an array of seven daily sales values.
  2. Check the array shape and data type.
  3. Calculate the average and total.
  4. Flag values above a chosen target using a condition.
  5. Reshape twelve monthly values into four quarters.
MATPLOTLIB

Chart building

  1. Make a line chart for daily revenue in date order.
  2. Add a meaningful title and axis labels with units.
  3. Compare three store totals with a bar chart.
  4. Inspect delivery times with a histogram.
  5. Save a figure and reopen the image to check the layout.
SEABORN

Pattern finding

  1. Explore customer visits against customer spend with a scatterplot.
  2. Compare satisfaction by team using a boxplot.
  3. Count orders by status.
  4. Compare a metric across categories with a barplot; explain its estimate.
  5. Check a numeric distribution and describe its shape.

YOUR PRACTICE CHECKLIST

Before you call it done

  • Can you state the question your code answers?
  • Did you inspect the inputs and the output shape?
  • Can you explain your assumptions and any missing data?
  • Does the chart have a clear title, labels, and units?
  • Could another person reproduce your steps?
